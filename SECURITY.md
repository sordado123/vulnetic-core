# Security reports

Do not disclose active credentials, private keys, customer data or executor access commands in public issues. Use GitHub private vulnerability reporting if it is enabled for this repository. Otherwise open a public issue containing only a request for a private reporting channel, without exploit details or sensitive attachments.

Scope assessments to systems you own or are explicitly authorized to test. Publishing code does not authorize testing the hosted Vulnetic service or any other third-party system. Preserve evidence privately and report product defects responsibly.
