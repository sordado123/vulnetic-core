# Contributing

Keep changes focused and explain the user-visible behavior. Preserve account ownership checks, PostgreSQL RLS, remote-only customer execution, human finding review and original executor deadlines. Add appropriate validation for changed logic; do not run paid model calls or tests against external targets without explicit authorization.

Public examples must use synthetic data. Do not attach credentials, customer evidence, execution tokens, private deployment settings or production logs to issues or pull requests. Retain upstream notices and document modifications.

This is an integrated AGPL-3.0 source release. Third-party licenses still govern their components. No CLA or extra restriction is imposed by this contribution guide.
